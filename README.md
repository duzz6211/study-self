# Study Repository

이 저장소는 **웹 기초, 자료구조, 알고리즘 등 CS 전반을 체계적으로 학습하고 정리하기 위한 학습용 저장소**입니다.  
각 주제는 **브랜치 단위로 분리**하여 관리하며, 실습 코드와 정리 내용을 함께 포함합니다.

---

## Repository Structure

학습 주제별로 브랜치를 분리하여 관리합니다.

- `study-html`  
  HTML, CSS, JavaScript 기초 학습  
  정적 웹 페이지 구조, 레이아웃, 스타일링, 기본 인터랙션 중심

- `datastructure`  
  자료구조 학습  
  배열, 리스트, 스택, 큐, 트리, 그래프 등  
  개념 정리 + 구현 코드 포함

- `algorithm`  
  알고리즘 학습  
  정렬, 탐색, 그리디, DP, 그래프 알고리즘 등  
  문제 풀이 및 접근 방식 정리

※ 브랜치는 학습 진행에 따라 추가될 수 있습니다.

---

## Branch Policy

- `main`
  - 전체 학습 구조 및 개요 관리
  - 실행 코드 없음 (README 중심)

- 주제별 브랜치
  - 실습 코드
  - 개념 정리 문서
  - 문제 풀이 기록

각 브랜치는 **독립적인 학습 단위**로 관리합니다.

---

- 개념 → 구현 → 문제 적용 흐름 유지
- 장기적인 학습 기록 및 복습용 아카이브
